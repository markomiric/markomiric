# Hi, I’m Marko.

I’m a senior software engineer in Rijeka, Croatia, and the person behind [KamaCode](https://kamacode.dev), my independent product and engineering studio.

I help teams build new products, improve existing software, and connect the tools they rely on. My work spans backend systems, web, mobile, and desktop, with design and engineering handled together.

## Products I build

- **[Kioku](https://kioku.moe)** brings your local anime files, watch progress, and playback into one desktop app. Pick up where you left off. **Public beta for Apple Silicon Macs.**
- **[Augmeter](https://github.com/markomiric/augmeter)** helps you understand coding-assistant activity inside VS Code. It keeps local activity counts distinct from usage reported by connected providers. **Open source.** [Install for VS Code](https://marketplace.visualstudio.com/items?itemName=kamacode.augmeter).

I like clear interfaces, honest numbers, and code that’s easy to live with. Boring is a feature.
